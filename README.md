# mishell

mishell is a simple unix shell.

It can execute any command on path and have some builtins (help, cd, exit).

## References

[Tutorial - Write a Shell in C](https://brennan.io/2015/01/16/write-a-shell-in-c/)

## How to run

First you need to compile the code with make:

```sh
make
```

The the shell executable is created, so you can execute mishell:
```sh
./mishell
```
